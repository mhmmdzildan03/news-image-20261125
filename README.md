**The World in One Page — Wednesday 25 November 2026, late-final edition.** One 1024×1024 broadsheet image summing up the whole of Wednesday's world news: 26 verified stories with a source named on each, a region-count ticker, a WHERE IT HAPPENED dot map and a day-in-numbers box. This full-day edition carries the stories a morning-only page missed — the late ballistic strike on Kyiv, the New York close (Nvidia −3.9%, Dow holding 50,000, Brent $94.61), the Brooklyn jury's Huawei verdict, the Cairo tanker disaster and the day's diplomacy from Honiara to Athens.

The program (`main.ts`, Node 22, standard library only) copies the broadsheet `entry.png` beside it to `/output/entry.png`, deterministically and with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
